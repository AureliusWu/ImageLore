# Round 2 maintenance — 2026-11-14

Review sources: historical ImageLore PRs #1, #4, #11 and #13. Revalidated against the R1 main baseline before changing source.

## Reproduced behavior

- Saving a synthetic file to its hard-link alias passed the old canonical-path check and truncated the original to zero bytes on Linux. The new regression checks the bytes of both names before accepting an error.
- Reverting a prompt to its original value during an in-flight save left the database at the intermediate value; the actual Hook harness reproduced this for ordinary saves and saved revisions without calling another manual flush.
- A duplicate README current-version heading was not counted by either synchronization or verification. All regex replacements now count globally; version verification also rejects duplicate README markers.

## Changes and boundaries

File copies compare the opened handles before clearing destination bytes and keep those handles for streaming, retaining normal overwrite and permission behavior. This uses the already locked same-file 1.0.6 as a direct dependency; no new package version is introduced.

Acknowledged editor baseline changes trigger a fresh autosave effect. The existing debounce, queue, asset identity and late-response guards remain in place. The duplicate-import regression now includes previously empty visual DNA and verifies both text and CJK lookup.

The repository permits checked noreply candidates to be fast-forwarded. Maintenance branches therefore run the same frontend/native gates without needing a provider-generated PR merge commit. Main scans are not cancelled by newer pushes. Full sensitive information/history protection, native lint/tests and release signing gates remain enabled.

Local Linux validation records only frontend checks and extracted production filesystem helpers; it is not desktop acceptance. Windows native and PowerShell checks must pass for the exact candidate before main integration. No application packaging, installer publication, real user files or model inference acceptance is claimed.
