# v0.26.0 模型准备、取消与状态修复

日期：2026-10-01（Asia/Shanghai）。源码提交 `de8367a`，版本 `0.26.0` / schema `11`。本记录说明源码与回归，不把它等同于新 EXE 的原生模型验收；此前真实三图 CLIP 的证据仍绑定[模型验收](V0_26_MODEL_ACCEPTANCE.md)中各自产物。

## 已复现并修复

- 模型 HTTP 请求停在响应头或正文时，旧同步下载器没有应用层超时和可唤醒取消。改用模型专用 reqwest 异步客户端，在现有索引 worker 内驱动；等待网络期间每 250 ms 检查取消，取消后同一 worker 丢弃请求/正文和文件句柄，清理自己的临时目录，再发终态。连接超时 15 秒、停滞读取 30 秒、单文件总期限 15 分钟，不重试无限等待。
- 模型完整哈希、读取与逐图处理前后检查取消；等模型操作或数据库 mutex 时每 50 ms 检查，获取锁后再确认。准备资产枚举移到 worker，取消后不继续提交图片向量或执行尾部维护。
- 前端启动索引先等待事件监听注册成功，注册失败不创建原生任务；早到终态缓冲、当前 job 身份和关闭等待逻辑保留。取消 ACK 只确认请求已收到，关闭和重试仍等待 worker 终态。
- 下载/准备失败保留具体可恢复原因和权威最终 processed 数，不被旧 progress 覆盖。模型初始化和当前图编码期间明确提示取消等待的阶段。
- 模型读取失败清除对应 readiness。持久化 cache generation 与 readiness 在同一 SQLite 事务中更新，删除模型后迟到的旧查询成功或失败都不能覆盖新一代状态；无效 generation 或溢出保留原缓存，不静默重置。
- 语义候选的 `LIMIT 100000` 曾静默漏掉第 100001 项。确定回归使用 100001 条资产、仅最高 ID 的一条 512 维向量复现，现改为完整过滤候选；最终返回仍按现有最多 500 项规则排序截取。

## 保留的可信边界

生产下载仍只从固定公开 HTTPS 仓库和固定 revision 获取文件，不读取 HF 全局 token，不设置认证或 cookies，不记录临时签名 URL。保留默认环境代理路由；这不代表支持 Windows Internet Settings 代理。每个任务使用独立 staging 目录，失败保留旧目录与其他任务 staging；每个缓存路径内操作串行，原子发布及失败回退保留。

ONNX 保留精确大小和完整 SHA-256 校验，辅助 JSON 保留非空、大小和合法 JSON 校验。辅助 JSON 尚未固定 SHA，不能宣称合法 JSON 内容被修改也一定被可信检查拒绝。模型和派生索引不包含用户数据库、原图备份或 Vision 密钥。

取消是协作式的：单次文件系统/SQLite 调用、ONNX 初始化和单张推理仍不可抢占。本轮网络与 mutex 回归通过，不能由 250 ms 轮询推断全部真实模型取消都在 2 秒内。完整模型包包含多个文件，15 分钟是单文件期限；真实下载、初始化、逐图阶段分别测量。

下载器使用的超时语义见 [reqwest 0.12.28 官方文档](https://docs.rs/reqwest/0.12.28/reqwest/struct.ClientBuilder.html#method.read_timeout)。项目锁定依赖版本，不增加新的依赖版本；Tokio time 仅将锁定树中的既有版本声明为直接依赖。
