## 本次内容

- 继续提供本地图库、元数据、Prompt Revision、CJK/语义搜索、Visual DNA、Reference、Remix、Sidecar 与谱系功能。
- 加强历史 schema 1–11、备份/恢复、故障与中断保全、取消/关闭协调、坏向量和模型配套 JSON 完整性检查。
- NSIS 带有固定 DirectML 与必需 Visual C++ 运行库；实际安装的应用须与构建输出逐字节一致。
- 发布工作流保留前端、严格 Native、敏感信息扫描，以及 `0.19.0` 旧目录和 `0.25.1` 独立数据目录两条覆盖升级、正常关闭和业务数据回读检查。实际源码、运行链接和文件摘要见本次附带的 `release-manifest.json` 与 `SHA256SUMS.txt`。

## 安装、备份与回退

1. 支持 Windows x64，使用当前用户 NSIS 安装器。安装前正常关闭 ImageLore，并另存一份资料库备份。
2. 用户数据默认在 `%LOCALAPPDATA%/app.imagelore.desktop`，不在程序安装目录。数据库 schema 保持 11；覆盖安装不应重建或清空用户数据。
3. SQLite 备份主要保存元数据与关系，**不包含原图文件**；原图请另外备份。模型缓存也不等于数据库备份内容。
4. 不支持降级覆盖或让旧程序强行打开未来 schema。需要回退时保留当前数据原件，使用匹配版本与可验证备份；恢复可能失去备份之后的编辑。

本次不修改应用数据目录、不启用远程服务或自动上传图库。Vision 分析仍由用户显式触发；联网范围见仓库的本地数据与联网说明。
