# v0.26.0 原生内存隔离验收

测量：2026-10-01 22:40–23:40（Asia/Shanghai）；整理：2026-10-02。

本轮完成五组独立进程、各 10 分钟的真实 Windows 操作。五组各 300 步，操作、解码、控制台及运行时错误均为 0；全部使用普通 WM_CLOSE，保留进程句柄读取真实退出码 0，确认 CDP 端口释放，没有强杀。

**内存门槛仍未关闭。** 闲置与固定大图在本窗口通过；固定小图有一次进程采样缺口；连续换图和仅滚动缩略图仍超过 20% 增长预算。停止操作后的回落单独保留，不替换活动期终点、峰值或 WARN。

## 受测产物与口径

- EXE 来源：`cd220b2a48c2f94a44e88e0c905e3d66781f6d17`，版本 `0.26.0`，SHA256 `760A77637F1CEDCACCB4A1C7033FB8AAF0EAF93BA1260870ED7F54E6A117FAF9`。
- 使用有标记的独立 50k 合成图库，每组新建 ASCII WebView profile。共享图片派生磁盘缓存保留，组顺序及前后缓存文件数记录；不能声称各组磁盘或 OS 缓存相同。
- 每组先等待 20 秒，再按 2 秒一次操作测量 600 秒，随后被动观察 60 秒。进程内存约每 10 秒采样；准备期和被动尾段不计入活动窗口。
- 同时记录所属 Native/WebView 子进程的 Private Bytes 与 Working Set，以及 renderer 的 JS heap、DOM、当前图片解码与分页状态。Private Bytes 是私有虚拟提交量；Working Set 求和可能重复计算共享页，GPU 进程 Private Bytes 不能当作显存。
- 不进行页面重载、缓存清空、强制 GC 或产品 API 包装。测试过程中不并行编译、复制大库或运行其他模型验收。
- 这是该旧候选的 GUI 证据，不能替代后续语义修复源码、新 EXE 或签名安装器的验收。合成图库也不能替代自然图召回质量或实际 50k 模型编码。
